# personal-planning-agents

一份让 AI 助手帮你管理「个人规划笔记库」的 **AGENTS.md 模板**。

把本仓库的 `agents.md` 放进你的笔记库根目录后，支持 AGENTS.md 的编程 agent（Qoder、Claude Code、Cursor 等）在每次进入该目录时自动加载它，从而在帮你整理目标、计划、复盘、灵感时，始终遵循一致的命名、结构与写作风格。

## 解决什么问题

用 agent 协助做个人规划笔记，常见三个痛点：

- **风格漂移**：每次让 AI 记录都要口头重复一遍格式要求，换话题、换会话后 AI 仍会自由发挥，产出的标题、结构、命名五花八门，事后难以检索。
- **重复交代**：规范只存在于对话上下文里，换会话、换工具后一切归零，又得重新说一遍。
- **文件杂乱**：没有约定的 AI 会随意命名（`新建文档1.md`…）、把文件随手丢在根目录，笔记库越用越乱。

AGENTS.md 把规范固化成「每次进入目录自动加载的行为指南」，一次写好，长期生效。

## 快速开始

1. 复制本仓库的 `agents.md` 到你笔记库的**根目录**。
2. 通读并修改其中的约定，删掉用不到的条目（见[定制指南](#定制指南)）。
3. 在该目录里让 agent 开工，例如对 agent 说：*「帮我建本月目标笔记」* —— 产出即符合模板约定。

## 期望效果

```text
<你的笔记库>/                 # 根目录
├── agents.md               # agent 自动加载的行为指南
├── 目标/                    # 主题文件夹（按需建立）
├── 复盘/
├── 灵感/
└── 2026-09-05-月度目标.md   # 笔记命名：YYYY-MM-DD-主题
```

## 定制指南

模板每节都可按个人习惯调整：

| 章节 | 常见调整 |
|---|---|
| 目录用途 | 改成自己笔记库的实际定位 |
| 交流规范 | 语言（如英文）、篇幅偏好 |
| 文件命名规范 | 日期前缀格式、是否取消主题文件夹 |
| 笔记结构规范 | 增删固定章节（如增加「灵感记录」） |
| 目录结构约定 | 对应实际文件夹调整 |
| 任务执行偏好 | 是否要求 agent 先询问、步长偏好 |

> 建议：首次使用先删掉用不到的条目，避免过度约束；使用数周后，再把实际养成的习惯补回文件，让模板与真实工作流贴合。
